# Security

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately, either way:

- on GitHub: this repository's **Security** tab, then **Report a vulnerability**;
- by email: founders@generalsequences.com.

Describe what you found, how to reproduce it, and the commit or release you saw it in. We aim to respond within three
working days, and we will tell you when a fix is released.

## Supported versions

Before 1.0, only the latest release receives fixes.
